# Gesture Typing

滑行输入：手机（或笔记本触控板）作为一块空白触摸板，显示端展示键盘、光标、候选词和已输入的句子。

**在线地址**：<https://gesturetyping.com/>

## 使用方法

1. 电脑上打开 **Display**，页面会显示一个 4 位的 **Session** 码。
2. 手机上打开 **Phone**，点这个码完成配对。
3. 在手机上滑出单词，显示端给出结果。
   - 向上滑进**候选栏**，在某个词上抬手即选中；在 ⌫ 上抬手删除上一个词。
   - 向下滑到左下角的 **Clear** 并抬手，清空文字。

**触控板模式**（Device = Touchpad）：用笔记本触控板代替手机。移动即开始一个词，点击结束，**Esc** 退出。

**拼写词表外单词（OOV）**：用手机把光标移到首字母，停留 **1 秒**，看到
“Hold complete” 后抬手，进入拼写模式并确认第一个字母。绿色下划线表示尚未
提交的草稿。之后每次滑动并抬手，立即追加终点字母，不加空格，也不用再次长按。
向上滑进操作栏并抬手，可选 **⌫ Letter** 删除末尾字母、**✓ Commit word**
提交整个词并退出，或 **× Cancel** 放弃草稿。若要替换已误识别的词，先删除该词
再拼写。Center 每个字母从 G 起步；Continuous 从上一个确认的字母继续。
拼写期间，底部 Clear/Undo 区域不起作用。

**Collection 中也可拼写**：保存句子前须先提交或取消草稿；跳过句子会把草稿保留
在采集事件中。需同时更新前后端。触摸被系统取消时不会确认字母。

**显示风格**：左下角的半圆图标在两种外观之间切换，选择按浏览器保存。

右下角的版本号用于标识当前构建。
