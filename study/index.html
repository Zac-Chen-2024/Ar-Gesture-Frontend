Gesture Typing User Study

显示端被试看的屏幕（电脑或头显浏览器），全程不需要点击 手机配对 → 开始问卷 → 黑屏触控板 → 结束问卷 主试控制台另一台设备：建会话、开始/暂停/重做、实时镜像、记录 句子采集电脑打开，手机配对后逐句采集（Collection）

一次实验的步骤

  1. 显示端打开 run.html，屏幕上出现 4 位会话码。
  2. 控制台输入口令 → 连接服务器 → 点这个会话码 → 输入被试编号（P01…）→ 建立会话。
  3. 手机打开 pad.html，输入会话码；被试填开始问卷，之后手机变黑。
  4. 控制台按 S：练习 → 正式 block → 屏幕评分 → 休息 → 下一个条件 → 结束问卷（手机）。
  5. 被试只用一种动作：按下 → 移动 → 松手。往上 = 候选词 / ⌫，往下左 = Clear / Back，往下右 = Next。

中断后用同一编号再建立会话即可从中断处继续。完整数据在服务器上用 export_study.py 导出。
